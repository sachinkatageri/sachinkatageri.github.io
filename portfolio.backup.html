01 · Learning · Marketplace · Enterprise LMS

MyNuclo

Product strategyUX architectureUI designDesign system

Evolving an existing learning platform into a broader marketplace and LMS ecosystem with learning paths, knowledge hub, surveys, assessments, payments, role-based access and enterprise workflows.

Problem

MyNuclo started from an existing learning platform and needed to evolve with broader business and market requirements while supporting more learning and marketplace capabilities. The challenge was keeping multiple roles, permissions and workflows understandable as the product expanded.

My role

  • Requirements and stakeholder alignment
  • User research and competitor pattern review
  • Information architecture and user flows
  • Wireframes, prototypes and high-fidelity UI
  • Design system, documentation and engineering handoff

Design challenge

The product combined marketplace, learning, feedback, assessments and enterprise workflows. I focused on the primary task for each user, progressive disclosure, reusable patterns and role-specific experiences so the platform could remain scalable without overwhelming users.

Impact

30% reduction in administrator task time for the Nu360 feedback experience, supporting structured reporting across 50+ enterprise clients.

02 · AI · No-code · Workflow automation

AutoCRUD

AI UXVisual workflowsMulti-agentAutomation

A unified platform for designing and deploying AI agents and multi-agent workflows, built to streamline complex operations and make automation approachable without writing code.

Visit AutoCRUD ↗

Product challenge

AI workflow automation can quickly become difficult to understand when users have to manage agents, integrations, conditions, loops, APIs, data processing and execution states. AutoCRUD brings these capabilities into one visual workflow environment.

Core experience

  • Visual drag-and-drop workflow builder
  • React Flow-powered visual editor
  • 50+ pre-built workflow node components
  • Multi-agent orchestration with context passing
  • Smart loops, conditions and dynamic routing
  • Universal REST API and webhook connections
  • Data processing pipelines and custom code execution
  • Communication, notifications, triggers and scheduling
  • Real-time workflow monitoring, logs, retries and alerts

Scale

The platform is positioned around 200+ integrations, combining workflow automation, AI agents, smart data tables, analytics and collaboration into one no-code product experience.

Design focus

The design opportunity is to make technically complex automation legible: show the workflow structure visually, preserve user control, make states obvious, and reduce the amount of technical knowledge needed to create and debug a flow.

03 · QA · AI · Test management

TestKase

AI test generationJiraQA workflowsReporting

TestKase uses AI to auto-generate test cases from Jira stories — turning hours of manual work into seconds inside the tools QA teams already use.

Core problem

Manual test case creation takes time and creates opportunities for inconsistent coverage. TestKase focuses on turning existing Jira story context into structured test cases faster.

Key features

  • AI test case generation from user stories
  • Folder-based test case organization
  • Test plans and test cycle execution
  • Real-time reporting and tracking
  • Direct linking to Jira issues for traceability

Product experience

TestKase is built natively on Atlassian Forge, so the QA workflow stays inside Jira without external logins or a separate workspace.

Reported result

Up to 80% faster test case creation, with a focus on better coverage and fewer bugs reaching production.

Installation flow

Admins discover TestKase through Jira's Apps experience, select the app, choose Get app, and start using it from the installed Jira environment.
